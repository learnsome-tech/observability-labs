### Design one page for one incident question

1. Write the user facing question at the top
2. Choose one headline, one breakdown, and one time series
3. Add a link that leads from the symptom to evidence

> **Hint:** Delete any panel that cannot change the next action.

## Check yourself

- Who is the dashboard for and what decision does it support?
- What do headline, breakdown, and time series each add?
- Why can a mean be a poor headline for latency?
- Which context should every panel make visible?
- When should a panel be removed?
